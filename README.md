# Fluffy Lineup — Portfolio Case Study

A bilingual project showcase for **Fluffy Lineup / 绒星排排乐**, a cozy
eight-player creature auto-battler designed and developed by **Xitao Liao**.

## Highlights

- English and Chinese presentation
- Responsive desktop and mobile layouts
- Gameplay loop, feature, gallery, and development sections
- Real in-game screenshots with a gameplay-video placeholder
- Accessible controls, alt text, and reduced-motion support

## Local development

```bash
pnpm install
pnpm dev
```

Production validation:

```bash
pnpm build
node --test tests/rendered-html.test.mjs
```

The gameplay poster can later be replaced with a recorded Steam Demo video.
